# 实现、证据与验收

## 数据与工具

先识别输入是原始数据、处理结果、原图还是仅有设计参考。保留字段、单位、坐标系、基准和处理记录。定量重绘使用用户数据及可核对的处理；只给截图时，不能根据视觉估数后输出成原始研究曲线。用户明确要求数字化时，保留数字化来源、分辨率与误差身份。

数量图使用当前适用的可复现绘图工具；空间网格、复杂场景或交互可选择相应专业工具。需要编辑已有图像时遵循当前图像编辑工作流，并核对科学内容。概念图或流程图依据明确关系绘制；图像生成不得造出实验、观测或模型证据。

核验本机解释器、依赖、字体和导出能力，不固化其他设备环境。Matplotlib 任务可以加载本技能 `scripts/figure_style.py`，调用 `apply_style`、`add_panel_label`、`style_3d_axes`、`export_figure`；脚本负责样式，不负责统计模型或原始数据验证。

环境检查应包含小型实际绘制，不只检查包能导入。Windows 下直接调用 Conda 解释器时，若 NumPy 线性代数或三维渲染报告动态库错误，优先通过当前环境的激活方式启动，并核对该环境的动态库搜索路径；不通过猜测旧电脑路径或改动全局环境解决。

## 常见处理的必要记录

| 处理 | 应说明或保留 |
| --- | --- |
| 密度／分布 | 样本、归一化、分箱／带宽、共用尺度与错开量；不伪造密度峰 |
| 插值／平滑 | 原始支持范围、方法、参数、缺测掩膜；不跨类别或未采样区域制造连续证据 |
| 热图 | 行列定义与顺序、标准化／变换、颜色范围、聚类或筛选依据 |
| 气泡 | 数量到面积／其他大小的映射、单位，及由同一映射生成的图例 |
| 降维／拟时序 | 方法与参数、图轴身份、排序定义；不当作实测地理坐标或时间 |
| 时空体素 | 网格、时间步长、阈值、空间／时间邻接及分裂合并规则；缺测与未达阈值分开 |
| 多图比较 | 相机、轴、图例、变换和范围可比；必要差异明确说明 |

根据实际任务记录相关项，不要求所有图都执行全部处理或建立额外方法研究。

## 分层检查

1. **内容与计算：** 图中量、单位、正负号、样本、坐标与源数据一致；不把推断、示意和观测混同。
2. **视觉编码：** 每种位置、色彩、大小和连线有定义；图例／色标正确，排序和共享映射一致。
3. **最终尺寸：** 打开实际导出的图，检查最小文字、细线、比例尺、密集热图标签、面板编号和留白。放大可读不等于缩印可读。
4. **三维特有问题：** 关键结构没有因相机和遮挡丢失；时间与深度、投影与主数据、等比例与垂向夸张可分辨。必要时添加二维视图或切片。
5. **文件与可编辑性：** 检查交付格式能打开、字体和对象未被意外栅格化，代码／配置可再生成；分别说明实际完成的检查。

关键图应目视检查，文件存在、XML 包结构或单纯代码运行成功不能替代渲染验收。若目标软件未能验证某项编辑性，准确说明该项，不把替代物包装成同等交付。

## 交付纪律

交付本次要求的图、必要的可编辑源或代码，以及简明图注／编码说明。合成或演示数据显式标识，不能混入真实结果。原始出处、处理日志、数据定位与校验信息放工作记录；正式图注保留理解证据及按实际授权使用素材所必需的信息。

PPT 页面备注是否允许来源、讲稿格式和整页布局服从当前 PPT 技能与用户要求；本技能不通过绘图任务重设整套演示文稿规范。
