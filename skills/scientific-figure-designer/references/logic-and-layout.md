# 从科学问题到多面板组合

## 先给图和面板分工

写一句主问题，再为每个面板注明它提供的证据：对象／流程、数据结构、条件响应、机制解释、对照、独立检验或适用边界。以这些关系安排阅读路径，不先凑几种图型。

参考图可抽象成三种常用组合：

- **流程与机制 + 性质空间：** 左侧交代输入、筛选和设计逻辑，右侧展示分类依据或定量分布。流程箭头不等于实验验证。
- **联合状态 + 响应曲线：** 三维图展示样本组合，二维小图比较策略、交叉点、变化幅度和区间。每种表现承担清楚的任务。
- **计算发现 + 多类支持：** 嵌入或分群、标志特征、趋势、热图、关联和原始图像相互补充。只有设计和数据支持时才把某面板称为验证。

不是所有图都要完整包含这些环节。缺乏因果检验时，机制解释或概念假说应保持其证据身份。

## 编码选择

| 主要任务 | 可考虑的表现 | 先检查 |
| --- | --- | --- |
| 精确比较量值／趋势 | 位置、长度、二维曲线、小多图 | 基准、单位、轴与区间是否可比 |
| 三变量联合分布 | 三维散点、成对散点、分层二维图 | 第三维是否必要，遮挡和相机是否影响判断 |
| 多条件分布形状 | 共尺度密度／脊线／瀑布分布图 | 归一化、带宽、偏移及高度含义 |
| 多变量模式 | 热图与注释条 | 行列顺序、变换、色标、缺测与分组 |
| 时空单元与事件结构 | 体素、分层／切片、事件单独视图 | 网格、时间步长、邻接及连接规则 |
| 方法与机制 | 流程、结构示意、步骤对照 | 箭头和形状是否对应实际科学关系 |

## 布局与对齐

先做不含装饰的线框布局，确定主面板、辅助面板、共享图例和色标位置。主次由证据任务与信息密度决定，不强制等大面板。

- 对齐绘图区、列边界和基线；不能只对齐各软件图片的外框，因为外边距不同。
- 相关面板适当靠近，独立任务用留白分开；标题、编号、图例与数据保持稳定间距。
- 共用时间／条件轴的小多图保持顺序、方向、颜色与线型一致。需要直接比较量值时统一范围；不同指标不能仅为整齐强制同尺度。
- 共享图例减少重复，但需要单独引用的面板仍应能独立理解。面板字母的顺序与实际阅读路径、图注一致。
- 热图等密集面板给足面积；标注只展示论证需要且能读清的子集。必要解释放图注或配套表，不靠无限缩字。

## 读图成本检查

读者应能指出：每个对象代表什么、视觉变量对应何种数据、哪些面板可比、它们共同支持什么。若必须反复猜颜色、寻找编号或旋转视角才能理解，优先简化编码或调整组合。

图注应交代必要的样本、统计量、区间、归一化、模型或示意身份。制作路径、日志和内部核验记录保存在工作文件，不挤进科学图注。
