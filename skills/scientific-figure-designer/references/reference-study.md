# 五张科研图参考截图的设计蒸馏

本报告依据用户提供的截图1—5，提炼图型选择、信息编码和组合方法。截图分辨率有限，以下区分直接可见的结构与可迁移建议；不能测定原始字号、精确色值、字体名称、区间定义、算法参数或论文来源。原图不存入本技能，以截图编号定位。建议的排版规则不等于对原图参数的还原。

## 截图1：多类三维图的参考拼贴

**可见结构。** 这张图集合了多种不同任务的三维表达：带数值标注的连续曲面、沿一维错位排列的分布曲线、分层平面或台阶曲面、拟时序相关曲面、三维散点及气泡图、离散方块与步骤图，以及包含场景和箭头的机制示意。它们不是一套统一的数据图模板，不能假定来自同一研究或共享变量、颜色与图例。

**选择逻辑。** 曲面适合展示响应量随两个变量的变化；分布切片适合比较第三个条件变化时的分布；台阶面强调分段或类别差异；散点保留个体分布；方块强调离散单元；场景图解释概念关系。选择的依据是数据结构与问题，不能只因为三维显得丰富。

**编码与阅读。** 先读坐标和单位，再判断高度、颜色、点径分别表示什么，最后看图例与局部标注。不同子图中的黄色、蓝色或红色各有局部含义，不能横向拼接成统一语义。曲面上的数值注释、散点的点径图例和机制图的箭头，分别提供不同信息。

**文字与组合。** 标题或面板号应先于坐标名进入视线，刻度和局部值随后；三维透视已经增加阅读负担，文字不宜随平面过度倾斜。可迁移的是图型分类和局部表达，不是整页拼贴。实际论文应选取同一问题需要的图型，统一视角、标签和边界；不要把多种三维效果同时堆进主图。

## 截图2：筛选流程与性质空间相互支撑

**可见结构。** 左侧a沿竖向展开：材料数据库和物性信息、溶剂与盐、聚类、目标材料、两种设计思路及最终目标。平行分支具有对应位置。右侧b、c上下排列，均为三维分类散点，HOMO与LUMO构成两条轴，竖轴分别表达不同能量量，并带底面投影和附近图例。

**选择逻辑与路径。** 先由a理解材料从哪里来、经过什么筛选，再由b、c观察类别在性质空间中的分布，最后回看设计比较。流程图承担方法与解释，散点承担数据分布，两者不必重复全部文字。底部目标框形成收束，但框内目标和对勾不等于实验已经验证。

**颜色与文字。** 流程使用蓝、青绿、红等块面区分节点或分支；散点用多类颜色对应图例。颜色是否能跨图共用，必须核对类别定义，不能仅因都标为某一Cluster就认定成员相同。面板号清楚定位，节点短标题高于框内细节，轴名高于刻度和材料示例；具体字形和字号无法可靠识别。

**可迁移方法。** 比较相同性质空间时，保持轴方向、范围、视角与点径原则一致；平行流程保持框宽、节点高度与箭头方式一致。只在第三维提供必要信息时使用三维散点，并检查遮挡。反例是两幅散点更换视角造成假差异，或用同一红色同时表达材料身份、差结果和实验组而不解释。

## 截图3：三指标状态空间配二维策略响应

**可见结构。** 左侧a以三个BE指标构成三维状态空间，气泡大小另编码Population；底部有三个低—高色带和点径图例。截图不足以确定点颜色的组合算法。右侧b由三行二维曲线组成，横轴均为Increment，纵轴为Exposure change，各行对应不同评价量；策略颜色跨行重复，曲线附近存在半透明带。

**选择逻辑与路径。** 左图回答样本在多个指标下处于什么状态，右图回答策略变化后各指标怎样响应。三维状态空间有其用途，策略之间的曲率、交叉和幅度则通过二维小多图比较。不能因为左图是三维，就把右图也改成三维。

**颜色与文字。** 右侧的颜色应稳定指代策略，排序也应一致；左侧的数值颜色与点径分别需要独立映射说明。每行的指标标题定位内容，轴名说明比较，刻度、策略图例和样本说明随后；网格与区间带应弱于主曲线。截图不能确定带状区域是置信区间、预测区间还是其他范围，绘制时须由真实方法定义。

**可迁移方法。** 共用x轴以支持跨指标比较；是否统一y轴取决于是否需要直接比较效应量。重复图例便于单图阅读，整版也可改为共享图例。反例是每行重新分配策略色、以直径映射数量却让读者按面积理解，或用平滑曲线暗示未经识别的因果效应。

## 截图4：计算发现与多类证据组成链条

**可见结构。** A为带类别标签的UMAP嵌入，并附Pseudotime小图；B组合群体或样本信息与标志表达分布；C含进展示意与拟时序、区域相关曲面；D为带顶部与侧边注释的表达热图；E为分区域的关联散点小多图；F为组织图像、局部细节、通道标签、方向信息与比例尺。

**选择逻辑与路径。** 可按“识别群体—支持身份—描述变化模式—汇总分子模式—检查关联—补充组织位置证据”阅读。这里提炼的是面板职责，不能仅凭排版认定研究已证明完整机制。热图压缩多变量模式，散点保留关联形态，组织图像提供另一类观察，三者不能互相替代。

**颜色与文字。** 细胞群类别色可在嵌入、分布图、热图注释条和散点间复用，但前提是定义一致。热图主矩阵的连续表达色、注释条的类别色和图像通道色应分别管理。A—F面板号建立定位，区域或模块名形成第二层，轴名与图例第三层，基因名和细节注释最小；不能为容纳更多标签而无限缩字。

**组合方法。** 热图和组织图像需要较大的连续面积；左右面板不必等宽。热图按真实的区域、亚型或排序规则分组，用细分隔线显示边界，说明归一化与筛选方法。组织图像先给背景再给局部，对应视野、通道和比例尺必须清楚。散点按列比较时统一坐标与相关系数的位置。

**解释边界。** UMAP距离不是实际组织距离，拟时序不是真实时间，箭头不自动证明谱系转换；相关系数不能直接写成调控或驱动。组织图像可支持定位、共现和形态描述，能否称为验证取决于研究设计、重复与定量检验。反例是用漂亮的连续曲面替代证据，或把图像通道颜色误当成细胞身份颜色。

## 截图5：经纬度—日期中的离散单元与扫描过程

**可见结构。** A将离散方块放在经纬度底图上，竖轴明确标为Date，颜色条表示Intensity；这里的高度表示日期，绝不是深度。B用Step 1—4展示方块扫描示意，并区分Hot day、Scanning day与Non-hot day。C沿日期叠放切片，以连线展示两个事件的跨切片组织方式。

**选择逻辑与路径。** 先由A理解研究对象在地理位置与日期中的分布，再由B认识扫描动作，最后由C理解跨日期单元如何被组织为事件。连续强度、离散扫描状态和事件归属是三种信息，分开表达比挤在同一组三维方块中清楚。

**颜色与文字。** A由浅至红表达强度；B的红、橙、浅色分别表示扫描状态或日类型，语义不同，不能默认整图红色总表示强度最高。A—C面板号建立章节，Date及经纬度轴名明确数据维度，步骤名与状态图例负责过程解释，刻度随后。地图边界、方块边线和网格应低于主要单元的视觉强度。

**可迁移方法与边界。** 可采用“数据对象—算法动作—结果解释”的三段式。相邻方块只是示意，截图不能确定空间或时间邻接、扫描顺序、合并与断裂规则，也不能确定网格和时间步长；不能照图自行补出算法。日期层间距、方块尺寸和透视可能受排版影响，不能据此读出地理距离或事件速度。需要复现时必须取得真实数据、方法和参数。

## 从五图提炼的实施与验收原则

1. 先写总问题，再为每个面板写一句证据职责；流程、观察、模型输出、机制解释和验证按实际证据使用，不强凑完整链条。
2. 先画灰度布局再加数据与颜色。主次依靠面积和位置，相关面板靠近；对齐绘图区、基线与列边界，不能只对齐导出图片外框。
3. 建立颜色字典，分开类别、连续量、正负差值及图像通道；同一语义共享，不同语义明确图例。颜色不足时用形状、线型和直接标签补充。
4. 三维必须回答第三维带来的科学问题。检查遮挡、透视和轴向；必要时辅以二维投影或切片，不把三维作为默认美化方式。
5. 字体层级按面板号、标题、轴名、刻度图例、局部注释组织。实际交付遵守用户偏好：中文宋体，西文Times New Roman，中英混排分别设置；不从低清截图反推精确字号与HEX。
6. 在最终发表或展示尺寸检查最小文字、图例、比例尺、热图标签与线条。能放大阅读不等于交付尺寸可读；导出后重新检查裁切、符号、上下标和颜色映射。
