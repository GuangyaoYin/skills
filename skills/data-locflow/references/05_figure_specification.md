# 通用图件与审计规范

本文件规定通用地震工作流的图件清单、最小输入、筛选、样式、产物和验收要求。图件依据本次运行的冻结输入生成，不依赖特定研究区、月份、事件数量、台网、外部目录或历史绘图脚本。**这是待实现的规范；列入清单不表示该图或整条计算链已经实现、运行或验收。**

字段和单位以[输入与目录契约](02_inputs_and_catalogue_contract.md)为准，运行目录和任务状态以[目录与复现规范](04_folders_and_reproducibility.md)为准。机器可读图件清单见[figure_plan.json](../assets/config/figure_plan.json)。

## 1. 生成范围与分层

图件分为核心、阶段诊断和可选插件，共32个稳定编号：01–22及30–39。核心图总结正式目录；诊断图检查已启用阶段；可选图依赖额外资料或专题分析。关闭或缺少输入时保留状态，不将后续图改号。

绘图只消费已产出的标准表、模型和经许可的背景数据，不能为补图启动检测、关联、定位、测幅或扰动计算。核心图也不能无数据强行生成：缺震级只跳过震级图，不能删除位置可信的事件；无有效样本不造占位点，也不借用旧运行结果。图号不是必须完成全部计算模块的要求。

正式目录由本次运行的manifest选择；主目录、完整字段视图、高质量视图和各阶段目录各有明确角色。默认统计全部已接受事件，任何质量筛选均显式配置、版本化并报告缺失/排除数量。不同来源或阶段的质量标签不自动代表相同定位精度。

## 3. 最小绘图模块输入契约

建议绘图模块提供`validate_inputs(spec, inputs)`与`render(spec, inputs, output_dir)`接口。模块不依赖工作目录、个人绝对路径或导入时读取的全局目录；通过明确对象/路径接收输入，只写本图登记产物。独立标准化适配器负责上游格式差异，绘图不根据UID、台站名前缀或文件名猜测科学含义。

| 输入角色 | 最小字段/元数据 | 仅对应图需要时必需 |
|---|---|---|
| 图件spec | `figure_id, stem, run_id, input_roles, selection, parameters, theme, enabled` | 全图；来源/阶段枚举从数据和配置派生。 |
| 正式事件 | `event_uid, origin_time_utc, latitude, longitude, depth_km`，以及来源/阶段映射 | UID非空唯一；UTC有依据；坐标、单位、深度基准和CRS明确。 |
| 震级绑定 | `value_column, type_column/type, method, qc_column`，及对应有效值 | 震级图；允许映射任意已声明标度，ML专用列只作为显式adapter，不承担所有标度。缺值不是0。 |
| 部署表 | `station_epoch_uid, network, station, latitude, longitude, elevation_m, start_time_utc, end_time_utc` | 台站/距离/波形图；缺时段ID时由适配器生成稳定映射，不能混淆移动部署。 |
| 拾取/关联 | `pick_uid, station_epoch_uid, phase, arrival_time_utc, probability`及membership/来源 | 到时图/关联诊断；未关联记录保留。继承/理论到时标`arrival_provenance`及原参考。 |
| 阶段/lineage | `event_uid, stage, source_partition, source_event_id, accepted, rejection_reason, fallback_reason`及阶段位置 | 阶段比较；内部ID有命名空间，失败/去重与回退可追溯。 |
| 残差/形式误差 | event-stage统计或逐观测表、单位、类型、方法/置信定义 | 不把事件汇总复制为逐观测表，不用未知补0。 |
| 模型 | `model_id, stage, top_depth_km/depth_km, vp_km_s, vs_km_s`及层界/梯度语义 | 模型图；阶段身份和实际采用状态明确，不猜缺失Vs。 |
| 可选测量/试验 | 波形索引、站次测幅、扰动或专题表及外键/方法版本 | 各自图件启用；实际基线、坐标与输入版本必须一致。 |
| 背景插件 | 几何/栅格、CRS/datum、出处/许可、版本/指纹及语义映射 | 只供已启用背景；未知datum标未知，不宣称自动完成精确配准。 |

所有输入另有`path/object_id, sha256或明确的内容版本, schema_version, units, timezone, crs`及缺失策略。图件使用的有效样本、排除原因、视图身份和匹配关系均可回溯。精确文件哈希未完成时明确标注，不以路径/mtime假称内容冻结。

模板匹配为可选来源扩展：关闭时单来源合法；启用后记录候选UID、源模板、相关系数/通道支持、相位来源、本地定位阶段和去重去向。新事件须本地求解，不复制模板或外部目录位置；继承S到时不是独立新拾取，误差不从模板/其他来源传播。不同阶段保留实际身份，不能因合并获得更高定位精度。

## 4. 文件、状态与审计

输出目录为本次运行的`products/figures/`，遵循[统一目录结构](04_folders_and_reproducibility.md)。每张静态图至少输出PNG、同stem的TXT/JSON以及可重建图的TSV：

```text
products/figures/15_absolute_relative_location_comparison.png
products/figures/15_absolute_relative_location_comparison.txt
products/figures/15_absolute_relative_location_comparison.json
products/figures/15_absolute_relative_location_comparison_stage_pairs.tsv
```

- **PNG**：通用主题默认300dpi，可配置；不默认生成PDF。交互HTML仅在相应插件启用时另行登记。
- **TXT**：输入角色/路径、选择与有效样本数、阈值、方法、单位、缺失/超界/排除、来源/阶段统计和限制。
- **JSON**：至少包含`schema_version, figure_id, run_id, implementation_status, artifact_status, inputs, selection, parameters, counts, excluded_counts_by_reason, units, timezone, crs, method, theme, software_versions, outputs, limitations`。输入/输出保存指纹；未知为null/unknown，禁止NaN/Infinity。
- **TSV**：保留UID、阶段配对、源行或分箱统计；海量原始记录可只引用冻结源表并保存聚合/选择规则。空子集写表头和0计数，不造占位事件。
- **manifest**：任务状态与全局统一采用`pending/running/failed/succeeded/skipped/invalidated`，另用`reason_code`区分disabled/missing_input/zero_samples等原因。`implementation_status`与`artifact_status`分开：规范清单中的`specified_not_implemented/not_generated`不等于运行成功。

必需字段/外键不合法应失败；关闭的插件正常跳过。输入不足时根据图件依赖标跳过或失败，不能生成无依据图。正式空区域可在明确允许时生成没有地震符号的基础地图，但它只能是已验收空选择的可视化，不能冒充完整目录验收或用虚构点填空。新运行不会因存在同名旧PNG就被标成功。

## 5. 通用可配置主题

### 5.1 文字与字号

默认不画图名、副标题、数据源、处理说明、总数`n=`、均值/分位数解释框或柱上样本计数。文件名表达图件主题，说明与数量在TXT/JSON/TSV中保存。坐标轴、单位、色标、图例类别、必要地名/地质单元、面板a/b和测线A–A′保留。数量作为科学纵轴和普通刻度正常显示。

用户需要的特定文字可在本图spec显式配置并审计，不扩散为全局例外。字号基于目标物理尺寸配置；建议坐标/轴名、色标和比例尺13pt，图例/必要地名及断层标签12pt作为起始主题，而非所有地图或版式的固定科学要求。小面板先调整画布和排版，避免任意局部缩字。

记录目标字号和实际渲染后端/版本，传播到图例、标签、色标及比例尺。后端若自动缩放色条文字，应通过明确的版本适配或测量使目标一致，不能把补偿值当所有后端通则。导出布局按最终dpi检查，图例放在不遮挡数据处，与轴标题保留可配置物理间距。

### 5.2 深度与其他色标

深度色标默认`auto`，也可由项目配置显式范围；不得固化特定研究区的深度上限。`auto`根据有效显示样本派生并保存解析后的数值范围；同组对照图先从共同总体解析一次，再共同使用，不能各面板独立变色。

色标只控制颜色映射，不筛目录、不改剖面范围、不截统计样本。超过显式色标端点的事件保留并使用端色；缺值有独立样式或明确排除理由。记录上下界超出数、缺值数和端色规则。若另设显示轴窗口，单独记录它及窗口外数量，不能与色标范围混淆。

概率、频数、残差、时间、密度采用各自量纲：例如概率0–1、带符号残差零中心、log频数的空网格区别于最低非零值、时间单调顺序配色。震级大小映射与图例一致，并明确是半径/直径/面积；不得凭颜色暗示不存在的物理变量。

### 5.3 地图与插件

地图范围、边界包含策略、投影、深度基准、比例尺参考纬度和图层顺序均由spec决定。基础地图不依赖地形、地名、河流、地质或外部目录；缺插件时正常绘制可用主体数据，记录缺失背景。

线与面使用完整几何裁剪，保留穿区线、多部件和孔洞；统计源要素、相交要素、裁切部分及无效几何。源datum不明就标未知；未经成立的坐标变换不宣称已转到目标基准或已精确配准。插件分类和数据值不能为排版被静默修改。

## 6. 后续实现边界与泛化验收

绘图适配层应参数化输入角色、路径、来源/阶段、时间范围、地理范围、台站部署与仪器分类、模型、筛选、统计方法、主题和输出路径。禁止个人绝对路径、固定月份/事件数、用UID推断来源、按站名前缀猜仪器、共享同名临时文件、导入即读科学目录/执行旧main或清理旧产物。绘图模块与检测、定位、测幅、扰动计算解耦，不借旧后端产物满足新run依赖。

实施验收至少覆盖：

1. **接口与样本**：最小契约、单位/时区/CRS、UID/外键、阶段配对与总数闭合；缺震级/误差不删合法位置。不同来源、单来源、模板启用/关闭均可处理。
2. **泛化配置**：不同年份/时长、范围、台网、台站部署、来源数和事件数均不依赖常量；阶段或背景插件关闭时不加载无关文件。
3. **科学口径**：CT/CC/绝对残差分开，误差方法与覆盖明确，模板继承观测不冒称独立拾取；震级类型/测幅台数/距离版本一致。
4. **颜色与视轴**：深事件超过色标上界仍在TSV与图中，auto对照色标一致；缺值、尾部、轴窗口外数量与审计一致。
5. **产物与状态**：同stem PNG/TXT/JSON/TSV内容一致，空结果可解析，输入改变使相应图失效；没有旧产物冒充成功，未实现与未生成状态不被计为完成。
6. **真实视觉**：在最终dpi/尺寸检查字号、色标端点、图例、长标签、边界符号及比例尺，无新增遮挡/裁切；默认无图名和解释性样本提示。
7. **资源与复现**：仅读必要表/索引，不重复扫描原始波形或隐式重计算；每图独立临时目录，固定随机抽样种子/算法版本，记录全部输入和输出指纹。

以上为后续开发的验收条件。只有对应模块在独立输入上实现并给出运行证据后，才可将其状态改为已实现、已生成或已验收；规范文档及图件清单本身不提供这些完成证明。
