# 03 震级与定位不确定性

本章面向任意研究区，规定从原始幅值到震级、从观测误差到定位不确定性的开发与验收方法。目标仪器、震级标度、响应、测幅窗、距离定义、衰减函数、质量门槛和误差模型均由项目选择并验证；已有经验参数不能自动成为新项目默认值。

**当前工作流包提供规范、配置与管理检查工具，尚未实现并验收通用测幅、标定、误差批处理的整链后端。**下文是适配器应满足的科学与数据契约，不代表每项方法已经接入可执行命令。字段关系见 [02 输入与目录契约](02_inputs_and_catalogue_contract.md)，实施状态与发布门槛见 [06 开发与验收](06_implementation_and_acceptance.md)。

## 1. 先声明震级标度与适用域

项目应先确定 `magnitude_type`，再确定相应的波形处理、目标响应、测幅量、距离修正和汇总规则。不能先算出某个振幅经验量，再仅修改字段名把它称为 ML、Ms 或 Mw。不同标度的测量对象、频带、距离与震级适用范围不同，混合比较前必须说明转换关系及其不确定性。[USGS 震级类型说明](https://www.usgs.gov/programs/earthquake-hazards/magnitude-types)

对局地震级，可选择经验证的目标仪器模拟幅值，例如所选规范定义的 Wood–Anderson 响应；也可建立明确命名、独立标定的项目标度。必须固定目标响应的极零点、归一化、灵敏度、输出单位及分量约定。物理地面位移、模拟仪器输出、最大绝对值和半峰峰值是不同量，不能混用同一组系数。选用其他震级标度时，应接入该标度对应的独立测量与验收模块，不默认沿用本章的局地幅值经验式。

每个已发布标定版本至少声明：

- 区域、时间、距离、深度和震级适用范围；参考震级类型及来源。
- 原始单位、响应版本、目标仪器或物理输出量、频带、窗口、分量组合和幅值定义。
- 距离与高程定义、系数及其单位、可选台站修正、事件汇总和质量规则。
- 训练、验证与独立检验的事件集合，外推标志，以及尚未验证的条件。

未完成标定或规范适用性核验时，幅值诊断仍可保存，震级输出标为未验证或缺测。`catalog_all` 可保留位置可信但震级缺测的事件及原因；需要完整震级的发布视图另行筛选，不能用零值填补。

## 2. 原始记录、通道与仪器有效时段

### 2.1 按通道和时段绑定响应

测幅使用未被神经网络归一化、自动增益控制或不可逆裁剪处理的幅值支路。原始记录只读保留，所有转换另存处理历史。按网络、台站、位置码、通道和记录时刻选择响应；设备更换、采集增益、固件或导出方式变化，必须拆分有效时段。部署时段与响应时段分别验证，不能仅凭台站名推断仪器。

标准记录应包括 `waveform_uid`、`station_epoch_uid`、通道标识与方向、起止 UTC、采样率、时钟状态、原始数值单位、传感器及采集器信息、响应有效期、原始文件与响应哈希。记录跨越响应或采集状态变化时，应拆段处理或拒绝该测幅窗。FDSN StationXML 可承载通道时段、坐标、方向和分级响应；实际使用前仍须检查输入输出单位与设备记录一致。[FDSN StationXML 官方参考](https://docs.fdsn.org/projects/stationxml/en/latest/reference.html)

### 2.2 响应去除与单位追踪

响应处理应形成完整的单位链：

```text
原始数值及单位
  → 可追溯的导出/采集增益处理
  → 去除记录系统响应
  → 所选物理量或目标仪器模拟响应
  → 按标度约定测幅并换算到明确单位
```

传感器灵敏度、采集器增益、响应归一化和导出缩放不能重复除去。若响应库已包含某一级增益，就不能再从经验字段扣除一次。PAZ 不足以描述完整采集链时，应使用有全部必要响应级的元数据或经审计的等效模型。

用 ObsPy 时，显式固定输出物理量、预滤波、水位、去趋势、taper、灵敏度开关及软件版本。`remove_response` 可输出位移、速度或加速度，其单位不同；水位与频带选择会影响结果，尤其在请求量与仪器原生响应不同时，不能机械沿用库默认值。[ObsPy remove_response 官方文档](https://docs.obspy.org/packages/autogen/obspy.core.trace.Trace.remove_response.html)

模拟目标仪器时应同时保存原响应和目标响应；明确目标灵敏度是否已乘入。ObsPy 的去原灵敏度与模拟目标灵敏度是两个独立设置，不能把“去响应”一词当成数值已自动统一的证据。[ObsPy Trace.simulate 官方文档](https://docs.obspy.org/packages/autogen/obspy.core.trace.Trace.simulate.html)

**验收要求：**使用具有独立已知响应与物理输入的合成记录验证单位和响应链；同一物理输入以不同原始单位或已知增益表示时，应在显式换算后得到一致结果。保存响应前后频谱、处理边界与有效频带诊断。原始单位、增益状态或有效响应不明时，不发布已验证震级。

## 3. 到时、窗口、分量与测幅筛选

### 3.1 用绝对到时定义窗口

按所选标度规定的震相或波列设置噪声窗、信号窗与处理缓冲。窗长可随距离、波列和记录条件变化，但规则必须版本化。保存绝对 UTC 起止时刻及参考到时，不能只存相对发震时刻的秒数。更新事件发震时刻时，应保持已经观测到的绝对到时不变，重新表达相对走时。

到时可能来自人工拾取、自动拾取、模板继承或理论预测，应分别标注来源和质量。模板相对到时不等于新增事件的独立观测；理论到时替代观测须作为独立方法验证。检查相邻事件污染、前后震波列、跨日缺口、滤波边缘及有效样点数，不能凭“成功读到文件”判定窗口有效。

### 3.2 分量组合是标度的一部分

项目应明确选择单分量、两个水平分量、旋转分量或其他合成量，并说明传感器方向校正。取最大分量、算术均值、几何均值及向量范数不能互换。非正交或方位未知的通道不能直接当作标准水平分量；分量缺失时采用拒绝、独立单分量标度或人工复核，不能静默补零或用其他方向替代。

例如，半峰峰值可定义为 `(max(x)−min(x))/2`，最大绝对值可定义为 `max(|x−baseline|)`；二者均须同时声明窗口、去基线规则、目标响应与单位。更改任一算子，应改变 `amplitude_method_id` 并重新验证与标定的兼容性。

### 3.3 SNR、削波与缺测

SNR 必须记录信号量与噪声量的完整定义：峰值比、RMS 比或稳健幅值比对应不同门槛。噪声中位绝对偏差可作为稳健估计，但不是 RMS；若做分布一致性缩放，保存缩放因子及假设。信号与噪声窗应处在同一单位、响应和处理状态。

SNR 门槛、最少样点、窗口覆盖率、有效分量数和削波判据均由项目在代表性样本上确定。硬件饱和标志、已知 ADC 量程、平顶和重复极值应结合检查；单一启发式不能证明没有削波。零或退化噪声估计不能生成无限高质量，NaN、无穷幅值、响应缺失、超过 Nyquist 的频带与无法解释的时间错位应拒绝或隔离。

输出所有候选记录，而非仅输出通过记录。至少保存每分量幅值、单位、噪声量、SNR、窗口、缺口、削波、方向和响应状态，以及接受/拒绝原因。阈值试验须比较检出偏差与震级依赖，不能只以通过率最高作为选择依据。

## 4. 距离、高程与最终位置

标定和应用必须使用同一 `distance_method_id`。项目可按所选规范采用震中距、震源距或规定的路径距离；保存地球模型、坐标基准、深度零点、台站高程、单位和算法版本。震级衰减距离与定位软件走时距离可以具有不同定义，但各自必须有依据，不能因名称都叫 distance 就直接替换。

若采用局部近似 `R = sqrt(Delta² + vertical_separation²)`，应声明 Delta 的计算方法及近似适用范围。深度向下为正、高程向上为正且使用共同零点时，垂直间距含事件深度与台站高程之和；相对地表深度、海平面深度和椭球高不能直接相加。是否忽略高程是显式的方法选择，需要与原标定一致并评估影响，不能成为隐藏默认。若采用三维坐标距离，也需保存坐标转换与基准。

位置、深度或台站坐标更新后，先核验旧幅值缓存的身份与距离，再用所选最终位置重算距离项、单台震级、事件汇总和质量标签。若绝对到时、波形、响应、测幅算子和接受集合未变，可以只重算距离项；否则应重新测幅或给出缓存仍有效的证据。记录旧/新位置、距离、震级、MAD、变化量及依赖哈希；不能仅把旧震级附到新位置。

距离复现容差依据坐标精度、数值算法和单位预算确定，不能把极小的浮点复现误差解释为同等科学准确度。超出标定距离或深度域的事件应标为外推，不得自动升级为高质量。

## 5. 区域衰减模型、可选台站修正与校准

### 5.1 统一写清模型和符号

对事件 e、台站有效时段 s，局地幅值标度可表达为：

```text
M_es = log10(A_es / A_ref) + G(r_es, h_e, phase; theta) + C_s
```

`A_ref` 指定与幅值同量纲的参考量，`G` 是所选项目或规范的距离/深度衰减修正，`theta` 为其参数；`C_s` 是可选的加性台站修正，正值在此约定下增加震级。所有量的单位、正负号、参考距离和零点必须随标定文件发布。

一种候选参数化是对数距离项加线性距离项及常数，但它只是可选择模型族，不是通用定律。分段函数、表格修正和近距离修正也需明确适用域、连续性及外推行为。地区衰减、短距离效应与台站效应可能不同，采用已有经验式之前仍需在项目数据上验证。[原始研究：Extending local magnitude ML to short distances](https://academic.oup.com/gji/article/216/2/1145/5185119)

台站修正应有足够的独立事件和距离覆盖，并与响应有效时段相容；通过约束或参考台站解决整体零点与台站项的不可辨识性。收缩、截断与缺样本站的处理须提前定义并验证。仪器类别偏移、台站场地修正和物理增益校正分别记录；经验偏移不能掩盖未知单位或错误响应。

### 5.2 标定与独立验证流程

1. 固定测幅、分量、距离、选台和汇总方法，再建立参考事件集合。核验事件身份、时区、震级类型、参考误差及双向匹配唯一性，保存全部匹配候选和歧义。
2. 评估参考样本的震级、距离、深度、空间、时段、仪器与台站覆盖。异质参考来源先处理标度差异，不能直接视作同一真值。
3. 以事件为单位划分训练、调参与独立检验，防止同一事件的不同台站记录跨集合泄漏；对高度相关事件家族、空间或时间外推目标，采用相应的分组留出。模型选择与最终性能报告使用不同层级的留出设计。
4. 明确损失、权重、约束和稳健方法。按站记录拟合与按事件等权拟合估计的目标不同；应与最终事件汇总量和项目用途一致。不能只让记录多的事件或台站主导标定。
5. 报告留出偏差、离散、MAE/RMSE等指标，以及随距离、震级、深度、台站、仪器和时段的残差趋势；同时报告未通过、缺测、外推和参考不确定性。
6. 单独验证台站修正的可复现性与留出效果。用于估计修正的参考事件不能再被称为独立验证；新台站或新有效时段不自动继承旧修正。
7. 冻结系数、协方差或参数重采样结果、参考集合、方法、适用域、软件版本和哈希。生产运行读取已批准版本，不在每个分区结束时无审计重新拟合。

参考不足时可以采用适用域明确的外部规范作为待验证起点，并说明证据与限制；不能自动借用邻区或其他仪器的系数，也不能靠调整常数使目录分布“更好看”。缺少足够独立检验时，标定状态保留未完成。

## 6. 事件聚合、MAD 与质量门槛

先按事件、台站有效时段和方法版本去除重复测量，再按配置聚合单台震级。中位数、加权中位数、稳健回归位置量、均值或截尾均值都应明确方法及适用条件；加权规则不能把相关分量或重复记录当作独立证据。异常台站拒绝需保存原值、规则、拒绝原因和接受状态，不能只留下更窄的结果。

规范字段 `magnitude_mad` 建议保存未缩放定义：

```text
M_event = median_s(M_es)                  # 选择中位数时
MAD_raw = median_s(|M_es − median_s(M_es)|)
```

若实际汇总选择其他方法，MAD 的中心仍须明确；若需要缩放为某分布下的稳健尺度，另存定义与系数，不将其混入同名字段。MAD 是站间离散，不是事件震级标准误或置信区间；共同响应错误、标度偏差与衰减模型错误可能不会增大 MAD。台站数很少或全部测量相等时，MAD 很小也不能证明准确。

项目质量门槛应在代表性验证数据上预先确定，至少考虑有效独立台站、距离/方位覆盖、响应与单位状态、SNR、削波、离散、标定适用域和参考检验。不同来源和定位阶段可使用各自已验证的门槛，必须保存规则版本。单纯定位成功、台站多或形式误差小，都不足以授予统一的“高精度”。

`magnitude_qc`、`location_qc`、定量不确定性及联合发布筛选分别保存。任何来源或阶段未经同口径评估时，保留 unknown/not_evaluated 状态，不继承模板、邻近事件或其他来源的误差。门槛不满足的可信事件可以留在完整追溯主表中，按用途生成派生视图。

## 7. 震级不确定性的组成

事件震级的误差预算应区分：

| 来源 | 可开展的评估 | 必须说明的限制 |
| --- | --- | --- |
| 幅值噪声与到时/窗口 | 符合噪声结构的模拟、受控到时与窗长敏感性 | 不能把改变波列定义的试验当成相同标度的随机误差 |
| 台站抽样与场地效应 | 留一台站、台站或相关台组重采样 | 分量成对保留；共同路径、仪器和台站相关性不应被拆成独立记录 |
| 响应与增益 | 有依据的响应参数情景和已知输入测试 | 共同单位或响应偏差不因增加台站数而消失 |
| 距离与位置 | 在所选位置分布或模型情景下重算距离项 | 位置散布未覆盖系统误差时，震级预算同样不完整 |
| 衰减模型与系数 | 事件/分组级重采样、参数联合分布和模型对照 | 应保留参数相关性，参数区间不能直接当成每事件预测区间 |
| 参考震级与样本选择 | 参考误差传播、独立留出和覆盖检验 | 训练内残差不等于外推准确度，缺测/截断可能引入选择偏差 |

每个区间应注明抽样对象、条件模型、重采样次数、中心与区间定义；用独立事件检验其覆盖。不能把 MAD 除以台站数平方根自动当作标准误，也不能无依据把多个相关误差项平方相加。只完成部分预算时，按已评估的条件命名结果，避免称为总震级误差。

## 8. 定位不确定性方法的选择

### 8.1 不同方法回答不同问题

| 方法 | 实际变化的对象 | 可支持的解释及边界 |
| --- | --- | --- |
| 线性化协方差/形式误差 | 固定模型与观测误差假设下的局部线性系统 | 条件误差；受线性化、权重、阻尼、秩与模型偏差限制，需核对求解器的实际输出定义 |
| 固定观测图加噪 | 绝对或差分到时；保持观测集合与链接 | 给定噪声模型和图条件下的重定位离散；不是观测块重采样 |
| 残差重采样 | 经过适当分层、中心化的观测残差 | 残差含模型误差或异方差时，不可直接当成独立同分布拾取误差 |
| 事件对/相关块 bootstrap | 一个事件对及关联观测，或经定义的相关块 | 反映该块抽样结构下的变化；需检查重采样后的图连通性与重复权重 |
| 台站/事件删除与 jackknife | 台站、事件或预定义群组 | 数据支持与网络结构敏感性；删除失败同样是结果 |
| 速度模型与结构情景 | 层速度、Vp/Vs、层界、侧向结构等合理候选 | 模型依赖；未赋合理概率的情景范围不是概率置信区间 |
| 初始位置、阻尼和权重对照 | 初始化、正则化、异常值规则及观测组合 | 数值与方法敏感性；不能代替观测误差标定 |
| 概率/贝叶斯定位 | 明确先验、似然与模型后的参数分布 | 后验区间依赖所设模型与先验，不自动具有外部频率覆盖 |
| 独立已知位置事件/外部约束 | 独立且质量可知的参考位置、深度或时刻 | 检验绝对偏差与覆盖；参考自身误差与代表性仍须计入 |

以上是可选择的方法族，不要求每个项目无差别运行全部方法。应按所选定位器、观测类型、台网几何和科学用途制定组合，并说明未覆盖的误差源。hypoDD 官方手册要求复核其求解误差，尤其是 LSQR 输出，并建议检查台站、速度模型、初始位置和事件集合变化，对适当子集进行 SVD 对照。[Waldhauser：hypoDD 方法与误差评估](https://www.ldeo.columbia.edu/~felixw/papers/Waldhauser_OFR2001.pdf)

### 8.2 噪声模型与次数由项目确定

噪声幅度应来自本项目的拾取验证、互相关时差稳定性或其他可追溯证据；可按震相、仪器、距离、SNR、相关系数、台站与事件类型分层。区分观测噪声和结构残差，必要时保留共享拾取、时钟或事件对导致的相关性。差分观测共享事件和台站，不应未经检查全部视为独立。

保存抽样分布、参数及其估计集合；不得固定一个通用噪声标准差。重采样次数由目标统计量的收敛试验、不同随机种子的一致性、成功比例和尾部分位数稳定性决定。请求次数不等于完成次数，完成一次重定位也不等于每个事件都保留。未达到预先定义的收敛或保留门槛时，输出不足以评估状态，而非用其他事件的统计量补齐。

### 8.3 随机、系统、相对与绝对分开

随机观测扰动主要描述所设噪声条件下的重复性。速度结构、台站坐标/时钟、坐标与深度基准、起始约束及响应错误可能造成系统偏差；对这些量固定不变的试验不能估计其影响。模型情景结果应与随机散布分别报告，除非有明示的联合概率模型及检验。

相对定位检验事件之间的间距与结构；绝对定位检验它们在地理坐标、深度和发震时刻上的位置。邻近事件的共同路径误差可部分抵消，但簇整体平移或整体深度偏差仍可能存在。分别报告簇质心变化与簇内相对变化，不能用窄事件带或较小相对散布证明绝对准确。[hypoDD 原始方法报告](https://www.ldeo.columbia.edu/~felixw/papers/Waldhauser_OFR2001.pdf)

与其他目录对比时，应核验事件身份、坐标/深度基准、时区和参考误差；差异说明的是两个解的差异，不自动说明哪一个是真值。模板新增、目录双差、波形双差和独立单事件解应分别核验误差范围，不通过合并目录提升精度等级。

## 9. 统计输出、失败与覆盖

每个事件至少保存方法和试验版本、基线解、实际样本数、请求数、成功数、成功率、位移中心、方向散布、分位数与缺测原因。记录统计量是相对未扰动基线、样本中心还是独立真值，单位是坐标值还是位移；地理坐标应经明确的局部投影或测地计算再得到水平距离，不能直接对经纬度差当作米。

“绝对位移分位数”中的绝对值运算不等于绝对定位准确度。单方向区间、水平径向分位数、三维联合区域以及事件总体的误差指标分位数也不能混称。后验可信区间、重复抽样置信区间、经验情景包络和样本标准差应各用正确名称；联合区域需声明构造方式和概率定义。

记录每次运行的退出码、收敛、残差、观测数、连通簇、被删事件、非物理解、簇质心位移与失败原因。对仅在部分试验中保留的事件，所报位置散布条件于保留，应同时呈现失效比例及选择效应。图件不得隐去显示范围之外的尾部或不成功事件。

若声明某概率水平的覆盖，应在独立且质量可知的验证集合上评估实际覆盖，报告参考不确定性与样本适用域。形式误差、重复运行稳定性、模型敏感性和独立绝对准确度必须分栏，不能用一个笼统的 error 字段代替。

## 10. 接入与验收契约

### 10.1 测幅和震级适配器

| 验收项 | 通过条件 |
| --- | --- |
| 身份闭合 | 全球唯一事件 UID；按通道及有效时段连接波形、相位、响应和台站，不因分区或来源重编号错连 |
| 幅值支路 | 使用可追溯原始幅值，输入单位、采集/导出增益与响应有效期齐全；独立已知输入测试通过 |
| 时间与算子 | 保存绝对到时、窗口与缓冲、实际采样率、分量方向和组合；缺测、削波、SNR及拒绝记录完整 |
| 距离一致 | 标定与应用的距离/高程版本一致；最终位置变化触发对应距离项与质量标签重算 |
| 汇总复现 | 单台震级、接受集合、事件汇总及MAD可由冻结输入复现，数值容差有依据 |
| 校准有效 | 系数适用域、参考身份、事件级留出与独立检验完整；台站修正有约束与留出证据 |
| 质量规则 | 门槛与用途事先冻结、经过代表性验证；缺测、未验证、外推与各来源状态清楚 |

### 10.2 不确定性适配器

| 验收项 | 通过条件 |
| --- | --- |
| 方法可辨 | 明确变化和固定的对象、抽样单位、噪声/残差模型、参数依据、随机种子及概率解释 |
| 实际运行可查 | 逐试验和逐事件保存请求/成功次数、保留率、失败、非物理解与网络变化 |
| 统计可复现 | 保存基线与所有有效实现、坐标变换、统计定义、中心和单位；不同种子及增加次数的稳定性满足预设要求 |
| 系统依赖 | 合理的模型、台站、初始化与求解参数敏感性按项目方案评估；未完成项明确标注 |
| 绝对/相对分开 | 簇整体与簇内变化分开；已知参考约束及误差可查，不以相对稳定替代绝对准确 |
| 范围安全 | 按完整UID、来源、阶段和输入版本连接；未评估事件不填零，不广播其他集合的误差 |

### 10.3 运行冻结与缓存失效

每次输出运行清单，包含解析后的项目配置、方法/系数/响应/距离版本、软件与可执行文件哈希、输入清单、已完成阶段和验收结论。缓存键必须覆盖会改变结果的全部依赖；恢复运行先比较旧清单与当前配置，不得读取旧汇总后用新参数替换其元数据。

测幅、距离更新、系数更新和质量重分类分别记录状态。响应、绝对到时、目标仪器、测幅算子、选台规则、距离定义或系数任一变化，应按依赖使相应缓存失效，并输出新旧差异；不能只因输出文件存在就视为完成。所有启用来源和阶段共享追溯规范，但质量门槛和误差覆盖以各自验收证据为准。

只有在代表性独立输入上完成响应/单位验证、区域标定、误差方案、失败恢复和输出验收，才能声明相应项目配置的科学后端可用。管理工具的预检或目录格式检查通过，不替代上述科学验收。
