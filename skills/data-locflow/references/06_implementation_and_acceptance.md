# 能力与实现边界

## 先确定本次工作

按用户请求执行设计、项目接入、检查、后端实现／运行、目录验收或绘图。已有项目和已授权步骤能推进时继续推进；科学计算接口缺失时描述具体缺口并完成其余可独立工作，不把计划、示例或旧结果当作新计算成果。

## 包内可执行能力

| 命令 | 作用与边界 |
|---|---|
| `plan --config` | 生成阶段依赖、预期产物和未配置输入；不启动后端 |
| `preflight --config` | 检查必需路径与类型、时区／范围、台站部署、标准模型和可选走时／层输入；可选读取ObsPy头，不读取波形样点做物理质控 |
| `audit-catalog --catalog` | 检查非空完整目录的字段、有限值、时区、UID／精确重复和可选范围／数量／来源；震级按类型统计 |
| `check-travel-table` | 检查REAL/FDTCC十列格式的数值、相位、节点、排列、缺失和重复；不是走时生成器 |
| `check-hypodd-model --input` | 检查NLAY／TOP／VEL长度、深度顺序、速度和Vp/Vs；不证明模型适用于该区域 |

使用Python 3.11+；头检查另需ObsPy。命令行选项以包内脚本`--help`为准。代码不包含任何区域模型、仪器响应或科学最优阈值。输入相对路径基于配置文件所在目录；所有项目产物写入用户run，保持skill资源只读。

模板未设置日期、范围、输入路径和科学参数是有意设计。`preflight`对缺少必需项目配置返回结构化FAIL；不能从案例或旧工程补值。基本输入检查通过不代表全部科学参数、响应、样点或后端已验收。

目录默认`magnitude`／`magnitude_type`。其他列名用`--magnitude-column`／`--magnitude-type-column`；缺类型列只能在已知标度时显式`--default-magnitude-type`。未知类型不能按文件名或数值猜测；不同标度不合并转换。

## 不随skill提供的计算能力

神经网络权重、PhaseNet／REAL／VELEST／ph2dt／FDTCC／hypoDD二进制及完整通用适配器不在包内。设备转换、波形样点与物理响应质控、实际测幅标定、不确定性计算、统一自动绘图和签名绑定的恢复也未由此检查脚本实现。

如果用户要实际运行，检查其环境内现有后端、适配器和版本；按当前任务推进缺失实现与代表性试验，不能运行一个不存在的通用`run`命令或承诺仅填波形／模型路径就能验证绝对精度。若用户已有成熟流水线，保留其明确选择，使用标准表及必要适配，而不是无条件替换。

## 开发和科学验收

- 工程验收：在隔离目录测试至少两套不同区域／年份／站网／模型／采样率的合成输入，覆盖跨时区、部署时段、错网格、层数、重复身份、混合震级类型、显式列映射和受控失败。模拟头与静态表只证明工程接口。
- 后端接入：用已知时移／到时和物理幅值核验转换、重采样、方向、响应和单位；检查事件对差分符号、全局UID、跨日合并及所有批次闭合。
- 科学验证：独立标注检验拾取／关联；用模型、台站和权重敏感性与可用独立基准验证位置；用项目适用的标度和留出事件验证震级。相对稳定性与绝对准确性分别声明。
- 恢复与发布：中断、损坏、输入变化和批次重分后与干净运行比较；签名不兼容即失效。主目录、派生视图与图件使用同一冻结版本，拒绝与缺测原因可追溯。

真实端到端验证必须在独立真实输入上完成，才能对该项目、版本和输入类型声明全链可用。格式检查PASS、skill安装成功或合成测试通过均不能替代它。
