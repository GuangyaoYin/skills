# 背景文献与原图

在用户同意检索补充研究背景，或已明确要求检索文献、找原文配图时使用完整流程。本次任务及其延续对话中的已有授权直接沿用，不为每次检索重复设置确认环节；其他 PPT 的授权不自动延续。未同意联网时，仍可按本文件的证据与图文核验要求整理已提供及获准的本地材料，跳过网络检索。

## 从研究问题建立论证

先读取用户论文、研究主线、关键结果、已有讨论和 PPT，确定听众需要理解的具体科学问题。保留用户的论述意图，核查其中的跳步与证据强度；把“领域已有认识”“仍存在的判断困难”“本文可提供的证据”连成可解释的关系。背景深度、次序与页数服从这个问题，不强制三段式或固定页数。

将用户提出的创新表述作为待核查主张，而不是检索前提。检查前人是否已经提出相似问题、给出判据、反例或解决方案；找到后如实介绍。区分“问题从未提出”“已有讨论但难以检验”“本研究提供新的案例或独立约束”，避免用检索不充分支持“被忽视”或“首次”。有争议时并陈证据和适用条件，说明本研究改变或补充了什么。

## 本地与网络检索

- 先使用已知项目目录、论文引用、知识库索引、先前会话给出的目录或已连接的知识库搜索能力定位相关材料。未知位置时优先发现可用连接、索引或项目内配置；必要时询问知识库路径，不盲扫全盘或读取无关私人目录。
- 知识库暂时无法访问时，说明实际覆盖范围和待查材料，继续可用材料及已获准的网络检索；不得声称已查本地库。网络查询使用概括后的研究对象、方法和公开关键词，不默认外发未发表结果、敏感参数、内部路径或整段研究文本；获取公开文献不等于获准上传本地研究材料。
- 在已定位的库内，结合研究对象、核心过程、诊断指标、因果判断、替代解释及其同义词检索。优先采用与论点直接相关的代表性原始研究；综述可用于找主线和追踪其引用，但不替代关键原文核验。
- 获准联网后，围绕本地材料的缺口和研究主张检索。优先期刊官网、DOI 页面、作者机构库及可访问的原始论文；记录所用版本。核验论文身份、正文、图注、方法条件和结论，不能仅凭摘要、搜索片段或二手转述选图并写机制结论。
- 形成轻量证据表：拟讲论点、原始文献实际结论、对应图/表、适用条件与限制、在本研究中的作用。证据不足时缩小主张或保留问题，不以无关文献凑数。

## 让图件承担论证

先决定图要证明或帮助理解什么，再选原文中的合适面板。可使用现象、特征、机制、反例或判别方法等不同证据，但不要把任一学科案例固定为所有汇报的背景模板。与本研究的过渡必须解释哪些认识可以迁移、哪些条件不同。

每幅采用的图在工作文件中绑定以下信息，可合并成一条简洁记录：

| 信息 | 记录内容 |
| --- | --- |
| 页面论点 | 该图实际支撑的具体陈述，而非笼统的“研究背景” |
| 原文证据 | 作者结论、图中观察或计算量及二者的关系；汇报者的推断另行标明 |
| 适用范围 | 对象、时间、空间、模型假设、接收条件、指标定义及影响解释的限制 |
| 可追溯来源 | 作者/年份、题名、DOI 或稳定 URL、文件版本、页码及图号/面板号 |
| 使用方式 | 原图文件位置；裁切区域/面板、局部放大或重组说明，及所保留的共用轴、色标与图例 |

核查图件和正文说的是同一物理量、同一事件/时段及同一模型条件。相关性图不能单独证明因果，模型机制图不能冒充实测，单个案例不能直接概括全部工业活动或全部地震。不要把原文未主张的解释写成作者结论，也不要把他人的结果写成本研究发现。

从可访问的原始 PDF、官方图页或作者版本提取图件，保持科学像素、比例、轴、单位、图例和色标。允许为投影可读性裁去空白、放大面板或重组原图裁片，并记录处理；不能裁掉改变结论的对照或反例。遵守 [页面与图件规范](slide-design.md) 的科研图、来源与备注要求。无法取得合适原图时改用其他已核验证据或标明缺口，不用生成图或猜测重绘代替原文证据。

## 转化为 PPT 并检查

取得初步证据后，按 [背景与问题访谈](background-grilling.md) 用 `grill-me` 与用户梳理背景和科学问题；新决策产生的证据缺口按本次检索选择补查。形成共识后再按证据关系完善逐页安排，说明每页为什么出现、图件如何支撑论点以及如何引出本研究。同一本 PPT 已完成并认可该阶段时复用结论；用户明确要求跳过访谈、直接制作时按其指令执行，不新增重复审批。

图文同页或相邻放置，避免背景变成文献清单。页面简引作者、年份和图号，备注保留完整来源、条件、必要裁切说明和讲述承接。让图中关键证据可读；必要时拆页或局部放大，而非堆图或依赖大量小字。交付前逐页核查标题主张、正文、原图与原文是否一致，并确认背景最终导向用户的具体研究问题。
