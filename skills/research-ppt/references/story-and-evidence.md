# 论证与证据

根据当前模式读取相应部分。以下内容是检查和组织依据，不是必填页序、固定章节或配额。

## 自己的研究与阶段进展

从本次最需要被理解、判断或讨论的科学问题出发，选择适合材料的展开路径。可从新观察、一个矛盾、关键方法选择、模型假设或待解释结果开始，再补足理解所需的背景。不要把按日期罗列工作代替科学论证。

帮助建立可追溯的关系：

- 本次试图回答什么？哪些认识或结果已经存在，哪些来自本次材料？没有前次记录时，不虚构“相比上次”的进展。
- 方法和数据为什么足以回答问题？需要哪些关键假设、边界条件、参数、对照或验证？只展开相关内容。
- 图件实际展示了什么？结论适用于哪个范围、比较基准和条件？观察/模拟与解释之间有哪些尚未证明的环节？
- 哪些结果相符、相矛盾或尚未稳定？替代解释是什么，什么观察、计算或分析能区分它们？
- 深入讨论怎样影响研究判断？把必要的机制、敏感性、数据限制和可检验预测放在相应证据附近，避免全部堆在结尾。
- 下一步怎样检验当前理解？提出与尚未解决问题相对应的工作，不编造已执行的实验或验证。

用户主线有跳步或证据不足时，引用具体材料解释问题，提出可选重排、需要补充的证据或更审慎的表述。已有材料中的关键反例不能因版面整洁而消失。

将“首次”“前人未研究”等创新表述作为待核查主张；有限的本地阅读或网络检索不能证明整个领域无人研究。按实际证据区分新问题、新条件、新案例和新约束，覆盖不足时明确限定表述。

## 文献汇报

围绕论文提出或解决的问题，组织理解所需的证据和细节。既可以沿作者论证，也可以为听众重排；保持图件、方法和结论的真实对应关系。

| 关注点 | 要讲清楚的内容 |
| --- | --- |
| 科学问题 | 先前认识的具体不足、论文所问的问题及为什么值得研究 |
| 证明方式 | 哪些主要结果、对照、独立证据或推导支撑核心论断 |
| 方法 | 方法原理、关键选择、假设、验证及适用条件，按理解需要展示原生公式 |
| 数据 | 数据来源、对象、覆盖、分辨率、样本或处理方法，以及它们如何限制解释 |
| 局限 | 证据缺口、作者承认的限制与汇报者自己的推断，明确区分来源 |
| 对自身研究的用途 | 可借鉴的方法、可检验的假设、数据需求，以及迁移所需条件 |
| 领域价值 | 该工作解决或新提出了哪个问题，改变、约束或补充了什么认识，还有哪些问题悬而未决 |

不要只复述摘要或逐幅贴图。选择图件时说明每幅图在论证中承担什么作用；方法和数据不能只剩名称。多篇文献可以围绕共同问题比较方法、数据和证据，不强制按每篇重复一套章节。

领域价值应有实质比较依据，不从期刊名、引用数或作者的“首次”措辞直接推断重要性。需要外部背景或争议证据时，遵循入口的本次检索选择，检索并核验原始论文或权威资料；用户未同意联网时使用获准材料，证据不足时明确限定判断。

## 证据记录与缺失信息

为实际使用的图、数据、公式和外部论断保留简洁定位：用户材料/原论文/补充文献、文件或 DOI/URL、页码/图表号、必要的数据处理说明。不要为了记录而加载无关私人文件。

纸面方案阶段即可指出待补材料，例如“这张图缺少单位，无法判断量级”或“因果解释尚无对照”。资料不足影响主线时与用户确定处理方式；次要缺口可标明后继续可完成的部分。

## 逐页共创

先完成 [背景与问题访谈](background-grilling.md) 中的 `grill-me` 阶段，将已明确的背景逻辑、科学问题、证据与剩余讨论项带入逐页安排；是否联网不改变这个梳理环节。

逐页安排应足够让用户判断逻辑和证据是否合适。例如用简洁表格列出页序、目的/要点、拟用图件/公式及出处、与相邻页面的关系、待讨论或待补项。按论证、图件和可读性需要拆分或合并页面，避免把一个完整推理拆成互不关联的口号。

首次制作先与用户确定主线和逐页安排，已有明确认可的安排则沿用。页数和时长服从本次要求；没有约束时根据内容建议，不将固定页数作为质量指标。
